## 双 ISP 家宽 IP 到底是什么意思，怎么自己验

这三个词经常被混着用，其实说的是三件不同的事。

**静态**指每次开机 IP 不变。动态 IP 一重拨就换，多账号环境里的登录地会突然跳变。

**双 ISP** 指这个 IP 在数据库里同时登记了两个 ISP 属性，且都指向家庭宽带，而不是数据中心。单 ISP 的住宅 IP 也能用，双 ISP 在风控模型里更接近"真实家庭线路"。

**原生**指 IP 段本身就在韩国，由韩国运营商分配，不是拿别处的 IP 中转伪装成韩国。

这三层叠加才构成"平台认为你是首尔本地用户"的效果。普通韩国机房 VPS 用的是数据中心 ASN，跑分可能很漂亮，但平台查一次 IP 类型就能区分开。

拿到机器之后自己验一遍，比看任何人的测评都可靠。查 IP 归属和 ASN 用 ipinfo，查风险评分和是否被标记为代理用 scamalytics 一类工具，两个结果对上了再开始投入运营。重点看三项：国家是不是 KR、ASN 是不是运营商而不是 IDC、风险类型是不是 residential。

还有一句必须写在前面：能不能解锁韩区服务，取决于分到的这个 IP，不取决于机器性能。同一个商家不同批次、不同 IP 段，结果都可能不一样。平台的风控策略也在变。任何"永久解锁"的说法都不用信，包括本文列出的任何清单。

WePC 官网对韩国线的功能描述集中在 TikTok 视频与直播推流，没有像部分同类商家那样列一长串流媒体名单。这和它的产品定位一致：这是一台给内容运营用的出口机，不是流媒体全家桶。

## 2 核配 512MB 内存，这个组合该怎么用

WePC 韩国线最容易被误读的参数是"2 核 + 512MB"。核数看着够，内存只有半个 G。

它之所以这样配，是因为这类 TK 专用机干的活很轻：视频编码和推流在你自己电脑上完成，服务器只负责把出口 IP 换成韩国住宅 IP，顺带跑一点代理或转发进程。CPU 给两核是为了转发时不吃紧，内存给 512MB 是因为正常负载下用不完。按这个用法，它是够的。

会撞墙的场景也很明确：

- 同时跑多个浏览器指纹环境做账号矩阵，512MB 撑不住几个实例。
- 想在服务器上直接装 Windows 或跑桌面软件，这个规格不用考虑。
- 在机器上跑重一点的转码、爬虫、数据库，内存会先满。

按场景对号入座：

**单账号养号、短视频切片上传** → WePC 这一档够用。2TB 双向流量对上传视频来说很宽裕，一天发几条片子远用不到。

**韩区直播** → 可以用，但联通必须配中转。另外算一下流量：2TB 是上行加下行合计，按 6Mbps 码率推流，一小时大约 2.7GB，理论上能撑 700 多小时；如果你把 100Mbps 带宽跑满，一小时就是 44GB 左右，2TB 四十多个小时就见底。实际直播码率远低于满速，但"2TB 很多"这个印象要按自己的码率和时长重算一遍。

**多账号矩阵、跨境电商常驻** → 512MB 偏紧，要么开两台，要么在结算页选更高一档的配置。

**只是想看韩剧、刷韩区流媒体** → 不用买住宅 IP。普通韩国机房 VPS 便宜不少，也能解锁大部分韩区服务，住宅 IP 的溢价只在 TikTok 运营、多账号、对 IP 风控极敏感的场景才划算。
